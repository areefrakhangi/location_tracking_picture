# 📸 Media Metadata Reporter (ExifTool + Excel)

A fast Windows/Linux tool to scan folders of photos/videos and generate a structured Excel report with GPS, timestamps, and metadata.

---

## 🚀 Features

- Recursive folder scan
- Supports images + videos
- Extracts:
  - Date taken
  - Camera model
  - Image/video dimensions
  - File size
  - GPS latitude/longitude
- Generates clickable Google Maps links
- Highlights files with/without GPS
- Progress indicator during processing
- Excel (.xlsx) output
